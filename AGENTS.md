## Automatic Operations (Windows + Linux)

Pavithra can run **repeatable, safe automation** on Windows or Linux: maintenance, monitoring, backups, installs, configuration, and “PC controller” workflows. This section defines what gets automated, how it’s scheduled, and the safety rails.

### Operating principles (non-negotiable)
- **Safety-first:** default to read-only checks, then propose changes.
- **Idempotent:** running automation twice should not break anything.
- **Logged:** every run writes structured logs (timestamp, host, action, result).
- **Rollback-aware:** before risky changes, create recovery points (Windows restore point / Linux snapshots when available).
- **No destructive actions** (delete, format, registry mass edits) without explicit user confirmation.
- **No credential leakage:** secrets only via environment variables / secret managers.
